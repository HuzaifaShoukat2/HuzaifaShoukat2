# 🔬 Research

## 🤖 AI-Driven Network Intrusion Detection System

I completed a research project investigating the use of **Artificial Intelligence and Deep Learning for network intrusion detection**, with a particular focus on the challenges created by **class imbalance in cybersecurity datasets**.

### 📊 Dataset

**CIC-IDS-2017**

The research investigated network traffic containing both benign and malicious activities and explored methods for improving detection of underrepresented attack classes.

### 🧠 Proposed Architecture

```text
              CIC-IDS-2017
                    │
                    ▼
          Data Preprocessing
                    │
                    ▼
            Class Imbalance
                    │
                    ▼
                 CTGAN
                    │
                    ▼
        Synthetic Minority Data
                    │
                    ▼
          Feature Engineering
                    │
                    ▼
          SHAP Feature Selection
                    │
                    ▼
                1D-CNN
                    │
                    ▼
               Bi-LSTM
                    │
                    ▼
          Attack Classification
                    │
                    ▼
          Explainable Results
```

### 🔬 Technologies & Techniques

* **CIC-IDS-2017**
* Python
* Machine Learning
* Deep Learning
* **CTGAN** — Synthetic minority-class data generation
* **SHAP** — Explainable AI and feature importance
* **1D-CNN** — Feature representation and pattern extraction
* **Bi-LSTM** — Sequential traffic pattern learning
* Data preprocessing
* Feature engineering
* Class imbalance analysis
* Model evaluation

### 🎯 Research Objectives

The research investigated:

* How severe class imbalance affects intrusion detection
* Whether synthetic data can improve minority attack detection
* Which network traffic features have the greatest influence on predictions
* The effectiveness of hybrid **CNN + Bi-LSTM** architectures
* How Explainable AI can improve interpretation of security predictions
* How AI-based approaches can contribute toward intelligent intrusion detection

> ✅ **Research Status: Completed**

This project strengthened my understanding of **cybersecurity datasets, machine learning, deep learning, synthetic data generation, feature selection, model evaluation, and Explainable AI**.
